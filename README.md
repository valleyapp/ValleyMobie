# VALLEY Mobile

VALLEY for iPhone and iPad (sideload) and Android.

## Source (AltStore, SideStore, Feather and other source-based installers)

Add this source URL once, then VALLEY installs and updates from it:

```
https://raw.githubusercontent.com/valleyapp/ValleyMobie/main/altstore/source.json
```

One-tap add:

- [AltStore](altstore://source?url=https://raw.githubusercontent.com/valleyapp/ValleyMobie/main/altstore/source.json)
- [SideStore](sidestore://source?url=https://raw.githubusercontent.com/valleyapp/ValleyMobie/main/altstore/source.json)
- [Feather](feather://source/https://raw.githubusercontent.com/valleyapp/ValleyMobie/main/altstore/source.json)

## Downloads

Get the latest iPhone `.ipa` and Android `.apk` from [Releases](https://github.com/valleyapp/ValleyMobie/releases/latest).
